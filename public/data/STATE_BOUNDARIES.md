# Límites de estados para detección local
Fuente: INEGI (2020), distribuido por geoBoundaries / William & Mary, gbOpen MEX ADM1. Se redondearon coordenadas a cuatro decimales y se simplificaron anillos a tolerancia 0.001 grados para uso de orientación. No apto para delimitar predios ni resolver límites exactos. Puede haber imprecisión cerca de fronteras estatales.
Metadatos: https://www.geoboundaries.org/api/current/gbOpen/MEX/ADM1/
